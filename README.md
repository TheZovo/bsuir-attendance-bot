# 🎓 BSUIR Attendance Bot & Telegram Mini App (TMA)

Telegram-бот и современное веб-приложение (Telegram Mini App) для автоматизации учёта посещаемости студентов с прямой синхронизацией расписания из **ИИС БГУИР** (`https://iis.bsuir.by`).

---

## 🌟 Основные возможности

### 👑 Для Старосты (и замстаросты):
1. **Интерактивный Журнал (Mini App)**:
   - Сводная матричная таблица (посещаемость за весь месяц / семестр).
   - Закрепленная колонка с ФИО студентов слева при горизонтальном скролле.
   - Быстрое переключение статуса посещения в 1 клик прямо в ячейке таблицы:
     - 🟢 **Б** — Был
     - 🔴 **НБ** — Неуважительный пропуск (2 академических часа)
     - 🟡 **УВ** — Уважительная причина (справка / заявление)
     - ⚪ **Оп** — Опоздал
   - Фильтрация по подгруппам (1-я / 2-я подгруппа) и живой поиск по фамилии.
   - Экспорт ведомости в **CSV / Excel** в один клик для деканата или куратора.
2. **Быстрая отметка прямо в Telegram**:
   - Кнопка **"📋 Отметить пару"** в чате бота.
   - Автоматически показывает предметы на сегодня из официального расписания БГУИР.
   - Интерактивные кнопки с переключением статусов студентов прямо в сообщении Telegram.
   - Кнопка **"✅ Все были"** для мгновенной отметки.
3. **Управление группой и предметами**:
   - Автоподтягивание расписания по 6-значному номеру группы (например, `310101`, `451001` и т.д.).
   - Импорт списка группы из ведомости деканата (просто вставьте текстовый список).
   - Добавление своих предметов (военная кафедра, факультативы, спецкурсы).

### 🎓 Для Студента:
1. **Личный кабинет в Mini App**:
   - Карточки сводки: сколько всего пропущено часов, сколько по неуважительной (НБ) и по уважительной (УВ).
   - Предупреждение о приближении к критическому порогу (20+ часов без уважительной причины).
   - Детализация пропусков по конкретным дисциплинам (сколько пропущено по каждой).
   - Полная история посещений с датами и статусами.
2. **Актуальное расписание**:
   - Автоматически рассчитывает текущую учебную неделю БГУИР (1, 2, 3 или 4).
   - Показывает время начала/конца пары, аудиторию, корпус и ФИО преподавателя.

## 🐳 Запуск через Docker (Рекомендуемый способ)

Проект полностью контейнеризирован и запускается через **Docker Compose**, где туннель вынесен в **отдельный независимый сервис**:
- `app`: веб-сервер Express, API, Telegram-бот и база SQLite.
- `tunnel`: отдельный контейнер `cloudflare/cloudflared` по протоколу HTTP/2, который автоматически генерирует защищённый публичный HTTPS-туннель и передаёт актуальный адрес боту.

### 1. Запуск всего стека (Бот + Туннель) в один клик:
```bash
docker compose up -d --build
```
или через npm-скрипт:
```bash
npm run docker:up
```

### 2. Управление контейнерами:
```bash
# Просмотр логов в реальном времени
docker compose logs -f

# Запуск только туннеля как отдельного компонента
docker compose up -d tunnel

# Остановка контейнеров
docker compose down
```

## 🚀 Локальный запуск без Docker (Node.js)

### 1. Требования
- **Node.js** версии 20+ (проект протестирован и оптимизирован под Node.js 24 со встроенной поддержкой `node:sqlite`).
- Токен Telegram-бота от [@BotFather](https://t.me/BotFather).

### 2. Установка
```bash
cd bsuir-attendance-bot
npm install
```

### 3. Настройка окружения (`.env`)
Отредактируйте файл `.env`:
```env
# Токен вашего Telegram-бота (получите у @BotFather)
BOT_TOKEN=1234567890:ABCdefGhIJKlmNoPQRsTUVwxyZ

# Порт веб-сервера Mini App
PORT=3000

# URL вашего Mini App (для локального тестирования http://localhost:3000, 
# для продакшена — домен https://yourdomain.com или ngrok tunnel)
WEBAPP_URL=http://localhost:3000

# Номер группы БГУИР по умолчанию (например, 310101)
DEFAULT_GROUP=310101

# Путь к базе данных SQLite
DB_PATH=./data/attendance.sqlite
```

### 4. Запуск
```bash
# Запуск в рабочем режиме
npm start

# Запуск в режиме разработки с автоперезагрузкой
npm run dev
```

После запуска:
- Сервер Mini App доступен по адресу: `http://localhost:3000`
- Telegram бот автоматически начнет принимать сообщения и команды.

## 📱 Настройка Mini App в Telegram через @BotFather

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram.
2. Отправьте команду `/mybots` и выберите вашего бота.
3. Перейдите в **Bot Settings** ➔ **Menu Button** ➔ **Configure menu button**.
4. Введите URL вашего приложения (например: `https://your-domain.com` или адрес из `ngrok`).
5. Задайте название кнопки, например: `Журнал группы`.
6. *(Опционально)* Для создания отдельного шортката Web App отправьте `/newapp` в @BotFather и укажите тот же URL.

> **💡 Подсказка для локального тестирования без белого IP:**
> Вы можете поднять публичный HTTPS туннель за 5 секунд через `ngrok` или `localtunnel`:
> ```bash
> npx localtunnel --port 3000
> ```
> И вставить полученную `https://...` ссылку в `WEBAPP_URL` в `.env`.

## 🛠 Интеграция с ИИС БГУИР

Бот обращается к следующим открытым эндпоинтам:
- `GET https://iis.bsuir.by/api/v1/schedule/current-week` — получение текущей учебной недели (1..4).
- `GET https://iis.bsuir.by/api/v1/student-groups` — список всех групп университета.
- `GET https://iis.bsuir.by/api/v1/schedule?studentGroup={group}` — полное расписание пар по дням недели, подгруппам, аудиториям и преподавателям.

Все данные автоматически кэшируются в локальной базе данных SQLite, благодаря чему система работает быстро и устойчива к кратковременным сетевым задержкам.
